# 磨刃排程台 · 滑雪板调校维护

面向雪板调校店的磨刃排程前端：工单登记板型与左右侧刃、底刃目标角度；派工选机器与槽位，按板长扣减砂轮寿命；完工登记实测刃角，超差退回；客户历史保留机器、槽位与实测角度，数据保存在浏览器 localStorage。

## 业务规则

- **派工冲突**（留在待排并写明原因）：机型不合（机器不适配该板型）、余量不足（砂轮剩余米数 < 板长）、槽位占用。
- **砂轮寿命**：按板长扣减（板长 cm ÷ 100 = 米），派工时一次性扣除；余量低于 2 米预警。
- **完工校验**：实测左/右侧刃与底刃角，任一偏差超过 ±0.3° 即退回返工，原槽不释放；合格才放槽完工。
- **客户历史**：每次完工登记（合格或退回）都归档机器、槽位与实测角度，按客户分组展示。

## 代码结构（规则 / 存储 / 页面分层）

```
src/
  domain/
    types.ts      # 工单、机器、槽位、历史记录等类型
    rules.ts      # 派工冲突、砂轮扣减、刃角容差等业务规则
  storage/
    store.ts      # localStorage 读写、演示数据种子
  ui/             # 页面组件（机器看板、登记表单、待排队列、在制列表、客户历史）
  App.tsx         # 页面组合与状态流转
```
